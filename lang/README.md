# Adhan Multi-Language Architecture & Roadmap

> **Language Strategy:**
> - 🥇 **Primary Focus (Phase 1):** **Tamil (`lang/tamil/`)** — Full Swaram tokenizer, Sangam & Thirukkural evaluation harnesses, Sandhi verification, and edge pretraining.
> - 🥈 **Secondary Bridge (Always On):** **English (`lang/english/`)** — Bilingual alignment, instruction-following, cross-lingual translation bridge.
> - 🚀 **Phase 2 Expansion:** Telugu, Malayalam, Kannada (Dravidian Cluster).
> - 🚀 **Phase 3 Expansion:** Hindi, Marathi, Odia (Indo-Aryan Cluster).
